Beneath the Legend

Privacy policy

Last updated: October 15, 2026

Who we are

Beneath the Legend is a YouTube channel about crime and mysteries (youtube.com/@BeneathTheLegendTV). "Beneath the Legend Uploader" is a private tool that the channel's owner uses to publish the channel's own videos. It is not offered to the public and has no other users.

What the tool accesses

With the owner's permission, given through Google sign-in, the tool uses YouTube API Services to:

  • upload videos to the owner's own channel and schedule when they go public;
  • set each video's thumbnail and upload its captions;
  • add the videos to the channel's own playlists;
  • read the channel's recent uploads, only to avoid uploading the same video twice.

It requests the scopes youtube.upload and youtube.force-ssl, and uses them only for the tasks above.

What we collect and share

The tool does not collect, store, sell or share personal data about viewers or anyone else. The only credential it uses is the owner's own sign-in token, kept as an encrypted secret in a private code repository and used only to publish the channel's videos. Video files are processed in temporary build machines that are erased when each job ends.

This website has no cookies, analytics, ads or tracking.

YouTube and Google

The tool uses YouTube API Services. Use of YouTube is governed by the YouTube Terms of Service, and Google handles data according to the Google Privacy Policy.

The owner can revoke the tool's access at any time on the Google account permissions page.

Contact

Questions about this policy can be sent through the channel's About page on YouTube.
